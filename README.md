# Turkish FrameNet 2.0

Code, data, and archived predictions for **“Turkish FrameNet 2.0: Synset-Level Frame Lexicon Expansion with Model Assistance.”**

Repository: https://github.com/emryurekli/trframenet-llm

The repository supports the paper’s three main empirical components:

1. a held-out benchmark of 1,673 Turkish verbal synsets;
2. a 967-item expert evaluation on the unlabelled expansion pool; and
3. a 400-item blind reannotation audit followed by independent expert adjudication.

No model output in the released expansion pool should be treated as a verified semantic annotation without expert review.

## Fast reproduction of the reported results

The following path does **not** call commercial APIs, download LLM weights, or retrain LoRA. It recomputes the metrics, confidence intervals, paired tests, subgroup analyses, expansion agreement, retrieval table, and resource-quality audit from archived predictions and annotations.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/reproduce_paper_results.py
```

A faster smoke test uses 500 rather than 5,000 bootstrap resamples:

```bash
python scripts/reproduce_paper_results.py --quick
```

A successful run ends with:

```text
REPRODUCTION STATUS: PASS
```

and writes all regenerated files under `reproduced_results/`.

## Sensitivity to accepted audit revisions

The [sensitivity supplement](sensitivity/README.md) provides the 400-item audit-to-benchmark crosswalk, the 101 expert-accepted reannotation decisions, rescoring code, and results. The audit includes 330 training and 70 test entries; 86 accepted decisions concern training entries and 15 concern test entries. Applying the 15 accepted test decisions changes 14 original test labels, because one accepted label already matches the frozen benchmark label. This is a separate scoring scenario: the original benchmark files, training labels, and model predictions remain unchanged.

Run from the repository root with Python 3.10 or later:

```bash
python -m pip install -r sensitivity/requirements.txt
python sensitivity/code/run_label_sensitivity.py --repo . --crosswalk sensitivity/data/audit_400_crosswalk.csv --output-dir ../trframenet-sensitivity-rerun --n-boot 5000 --seed 42
```

This command rescores archived predictions without model training or API calls. The output directory must be outside the source repository. The selected 70-item audit subset is diagnostic; it is not a representative sample of the full test distribution.

## Release-integrity checks

```bash
python scripts/validate_release.py
```

## What is fully reproducible from this package?

### Deterministic table reproduction

Fully reproducible without external services:

- Table 3 resource-quality adjudication outcomes and grouped error analysis;
- Table 4 diagnostic retrieval values;
- Table 5 primary benchmark metrics, bootstrap intervals, conditional accuracy, paired bootstrap tests, and McNemar tests;
- Table 6 expansion-set exact/soft agreement and paired tests;
- rare/common, MWE/single-token, and surface-overlap subgroup analyses.

The separate sensitivity command above reproduces the accepted-test-label revision analysis from the same archived predictions.

### Model regeneration

The repository also contains scripts and configuration for regenerating the supervised encoder and LoRA predictions:

```bash
pip install -r requirements-models.txt

python scripts/train_encoder_baseline.py \
  --train data/lexicon/train.csv \
  --test data/lexicon/test.csv \
  --output-dir regenerated_encoder
```

LoRA regeneration uses the exact training and inference scripts:

```bash
python scripts/train_lora.py \
  --train data/lexicon/train.csv \
  --output-dir regenerated_lora

python scripts/run_lora_inference.py --help
```

The repository provides the exact LoRA configuration but not the adapter weights. Archived parsed predictions support deterministic rescoring of the reported systems; complete raw API responses are not available for every system.

## Data files

### Labelled lexical resource

- `data/lexicon/turkish_framenet_2_annotated.csv`: 8,549 labelled Turkish verbal synsets across 846 instantiated canonical frames.
- `data/lexicon/train.csv`: fixed 6,876-item training partition.
- `data/lexicon/test.csv`: fixed 1,673-item held-out partition.
- `data/lexicon/expansion_target_unlabelled.csv`: 9,238 unlabelled records representing 9,237 distinct synset IDs, including one exact duplicate record.

The annotated and expansion synset ID sets are disjoint. Original records are preserved for reproducibility; see [data/README.md](data/README.md).

The primary columns are `ID`, `SYNSET`, `DEFINITION`, `FRAME1`, optional `FRAME2`/`FRAME3`, and `SYNSET_norm`.

### Expansion evaluation

- `data/expansion_eval/expert_annotations.csv`: 1,000 sampled target synsets, of which 967 have at least one expert-selected frame.
- `data/expansion_eval/model_predictions.csv`: archived predictions from the six systems reported in the paper.

The expert selected up to three ordered frames from the retrieved candidate set. These scores measure model–annotator agreement within that candidate space; they are not full-inventory inter-annotator agreement.

### Resource-quality audit

- `data/resource_quality/audit_records.csv`: analysis-ready anonymised record of all 400 items.
- `data/resource_quality/blind_reannotation_expert_adjudication_400.xlsx`: released audit workbook preserving anonymised notes, outcomes, codebook, and summary tables.
- `data/resource_quality/PROTOCOL.md`: exact audit design and interpretation.

A1 first reannotated the 400 items without seeing the released label or model outputs. A separate expert, A2, then reviewed each record using only the synset, Turkish definition, A1 decision, released label, and FrameNet evidence; A2 did not inspect model predictions. The audit has four equally sized, mutually exclusive diagnostic strata: rare frames, frequent frames, repeated/polysemous surface forms, and multiword expressions. Items satisfying multiple criteria were resolved during sample construction and are analysed under the final recorded stratum.

The final outcomes are 81 direct matches, 179 cases where the released label was retained after review, 39 cases where both labels were plausible, and 101 cases where the blind reannotation was accepted. The released label was therefore retained or judged plausible in 299/400 items. Because the sample deliberately balances four diagnostic strata, these rates are not corpus-wide prevalence estimates. Five omitted blind decisions were restored from the annotation record after confirmation that they matched the released labels. This is an expert-adjudicated resource audit, not a parallel two-annotator IAA study. The released label recorded in the audit workbook is tracked separately from the frozen benchmark label in the sensitivity crosswalk. The main benchmark results use the original frozen labels; the 101 expert-accepted decisions are released separately in [sensitivity/data/audit_101_decisions.csv](sensitivity/data/audit_101_decisions.csv).

## Archived raw outputs

`results/primary/primary_predictions.csv` contains the parsed per-item predictions used for benchmark evaluation and sensitivity rescoring. `results/raw_outputs/` contains the available raw primary-task outputs; the API JSONL files are empty, so they do not provide a complete raw-response archive. Earlier duplicate runs and intermediate caches are not included.
